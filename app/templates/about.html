About SafeLink

Understand suspicious URLs before you trust them.

SafeLink is an AI-assisted phishing URL detection system developed as an MCA final-year project. It analyzes the structure of a submitted URL and provides a risk assessment without opening the website.

What SafeLink does

The system examines URL-based characteristics such as URL lengths, subdomains, IP-address domains, digits, parameters, obfuscation patterns, and HTTPS usage to identify suspicious patterns.

Safe URL analysis

SafeLink does not visit the submitted website during analysis. This allows the URL structure to be examined without directly exposing the application to the destination page.

Risk results

Each scan provides a risk level and supporting information to help users understand why a URL may be suspicious.

Project technology

The application uses Flask for the web application, machine-learning techniques for URL classification, Firebase for cloud data services, and Render for deployment.
